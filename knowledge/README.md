# Материалы для SEO

Скопируйте сюда только выбранные заметки Obsidian в UTF-8. Сам этот файл не является инструкцией генератору.
В YAML оператора `operators/rusplast-seo.md` добавьте явный список, например:

```yaml
knowledge_files:
  - company.md
  - editorial.md
```

Без списка заметки не читаются. Подкаталоги разрешены. Отсутствующие, пустые,
слишком большие файлы и ссылки за пределы этой папки останавливают новый выпуск.
Лимиты: 20 файлов, 100 КБ каждый, 300 КБ суммарно. Указывайте только материалы,
которые допустимо передавать модели и сохранять в скачиваемом архиве выпуска.
Содержимое и SHA-256 сохраняются в context.json и передаются автору и редактору.
При повторе уже проверенной статьи используются ранее сохранённые материалы.
Обновление файлов влияет на новые статьи. Автоматическая синхронизация с iCloud
не настроена; пока обновляйте выбранные файлы вручную.
