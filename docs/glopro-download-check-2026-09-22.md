# Проверка загрузчика GloPro — 22.09.2026

## Исправления

«Сформировать» открывает `/reports/generate/` в новой вкладке; ответ содержит
XLSX-вложение. История заказанных отчётов загружается независимо и может добавить
несколько старых ссылок раньше получения нового файла. Прежнее сравнение ссылок
останавливало такой запуск с ошибкой неоднозначности.

Загрузчик теперь принимает нативное скачивание из браузерного контекста и сверяет
origin, путь, шаблон, период, формат, договор и фирму. Фирма передаётся в запросе
как родитель выбранного договора; имя поля договора читается из формы.
Дублирующиеся или несовпадающие параметры отклоняются. Кнопка формирования
нажимается один раз, история отчётов не используется как запасной источник.

Второй подтверждённый сбой происходил при `Locator.check` нативной радиокнопки XLSX.
Теперь нажимается видимый переключатель формата и проверяется состояние radio.
Проверка XLSX и атомарное сохранение через временный файл сохранены.
