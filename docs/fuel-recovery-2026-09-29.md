## Исправленные причины

1. GloPro показывал только десять последних операций. У активного клиента
   они уже были новее отчётной недели. Теперь такое окно требует свежего
   XLSX точного периода; оно не интерпретируется как отсутствие операций.
2. На этом Mac VPN-маршрут давал таймауты HTTPS обоих кабинетов, тогда как
   тот же запрос через физический интерфейс `en0` проходил сразу. Браузеры
   топливных операторов теперь используют ограниченный по доменам локальный
   CONNECT-туннель через активный физический интерфейс при обнаружении VPN.
   TLS проверяет браузер. Настройки VPN и маршруты системы не меняются.
3. Яндекс возвращает `StationCanceled` и `UserCanceled`; прежний код знал
   только `Cancelled`. Поддержаны только подтверждённые нулевые отмены.
4. Яндекс исключает такие отмены из Excel. Сверка сохраняет весь манифест,
   отдельно доказывает нулевые пропуски и требует каждую завершённую заправку.
5. Рекламное сообщение кабинета перекрывало кнопки отчёта. Используется
   стандартная клавиатурная активация точных кнопок без принятия оферт.

Дополнительно устранено противоречие бюджетов ожидания GloPro: запрос
генерации мог прерываться через 20 секунд, хотя ожидание файла длилось 120.
Теперь бюджеты согласованы, а HTTP/сетевые ошибки конкретной генерации
показываются сразу без повторного создания отчёта. Один промежуточный
таймаут СТЕПДОРСТРОЯ не воспроизвёлся в отдельной диагностике; его точную
причину нельзя задним числом приписать этому несоответствию. Последующий
полный запуск прошёл все фирмы, включая СТЕПДОРСТРОЙ.
