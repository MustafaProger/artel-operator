# Шаблоны топливных отчётов

## Общие правила отчётов

Согласовано 22.09.2026. Эта инструкция содержит шаблоны топливных отчётов разных поставщиков: GloPro, Яндекс Заправки и Лукойл. Правила одного поставщика не переносить на другого.

- Фирмы в итоговом тексте и сводном Excel располагать по алфавиту полных названий, без учёта регистра, кавычек и различия «ё»/«е». Содержимое и суммы при сортировке не менять.
- До формирования XLSX проверять наличие заправок за нужный период. При подтверждённом отсутствии операций не запрашивать и не скачивать отчёт. Отсутствие операций отличать от ошибки загрузки, истёкшей сессии и неполной выборки.
- В GloPro список последних транзакций ограничен: если все показанные операции новее отчётного периода, он не доказывает отсутствие заправок. Такой случай требует проверки/импорта, а не нулевого отчёта.

Отправка в Telegram отменена 22.09.2026. Результаты сохранять в файлы и историю запусков.

## Яндекс Заправки: недельное актирование

Выполнять только во вторник за предыдущий вторник–понедельник включительно, полные сутки по Москве (UTC+3). Пример: актирование 22.09.2026 за 15.09.2026–21.09.2026. В пятницу Яндекс не актировать. При повторе сохранять период планового вторничного запуска.

В кабинете Яндекс Go для бизнеса открыть «Заказы и отчёты» → «Заправки». Выбрать недельный период, UTC+3 и нужного сотрудника. Проверить завершённые заправки, затем сформировать новый отчёт; не подставлять старый файл из списка отчётов. Полный состав сотрудников определяется по заказам выбранной недели с проверкой всех страниц, а не по фиксированному списку или активному справочнику. Каждый user_id обрабатывается раздельно. В показанном кабинете сотрудник подписан «Джибраил»; в согласованной подписи использовать «Джибриль». Соответствие сотрудника проверять по кабинету, а не по похожему имени.

Файлы: `Яндекс. <имя>.xlsx` для каждого заправлявшегося; при совпадении имён добавляется устойчивый ID. Пустые выгрузки не создавать. Литры и сумму закупки брать из текущего отчёта, сверять с его итогами, учитывать подтверждённые возвраты со знаком минус. Сумма закупки — фактическая сумма поставщика; коэффициенты и скидки GloPro к Яндексу не применять. Литры и деньги показывать с двумя знаками после запятой.

Шаблон подписи (для Яндекса это исключение из общего правила не указывать период):

```text
<ДД.ММ> - <ДД.ММ>
Яндекс заправки
на склад (<имя>) <литраж> л на сумму закупки <сумма> рублей
```

Автоматическая выгрузка реализована через кабинет Яндекс Go: однократный вход в «Подключения → Яндекс Заправки», затем работа по сохранённой локальной сессии. API-ключ для этого способа не нужен. Срок действия входа определяет Яндекс; при повторном запросе авторизации нужно снова подключить кабинет. Литры берутся из «Залито», сумма закупки из «Стоимость»; «Запрос» не равен фактическому литражу. Импорт поддерживает проверенную XLSX-выгрузку кабинета с листом «Отчёт», реквизитами периода и итогами. Скриншот и пример суммы не заменяют исходный Excel.

## Лукойл: закупка на склад

Отдельный шаблон закупки Лукойла на склад Джибриля. Период, литры и фактическую сумму закупки брать из соответствующего исходного отчёта; не смешивать этот шаблон с обычными клиентскими расчётами GloPro или с разделом НК АРТЭЛЬ. Автоматическое подключение Лукойла этим шаблоном не задаётся.

```text
<ДД.ММ> - <ДД.ММ>
Лукойл
на склад (Джибриль) <литраж> л на сумму закупки <сумма> рублей
```

Литры и сумму показывать с двумя знаками после запятой. Числа из примеров не переносить в следующие периоды. Готовые результаты сохранять отдельно в `Работа/Активация — ДД.ММ.ГГГГ.md`, а не в этой инструкции.
