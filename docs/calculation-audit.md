# Проверка расчётов GloPro

Дополнение от 22.09.2026: для Китая и ООО «НК АРТЭЛЬ» действуют отдельные
[недельные правила и подтверждённые проверки](glopro-weekly-2026-09-22.md).
Ниже сохранена история реализации и проверок обычных фирм от 19.09.2026.

Модуль `operator_app/calculator.py` реализует действующую инструкцию из файла
`Второй Мозг/Артель/Расчёт топлива по картам glopro.md`, прочитанную 19.09.2026.
Исходная инструкция и прежние активации не менялись.

## Что считается

- ДТ и ДТ ЭКТО объединяются до расчёта цены. Возвраты сохраняют знак.
- «Стоимость ТО» определяет базу цены поставщика. «Стоимость» определяет оплату клиента.
- Для дизеля множитель равен 0,99 для виртуальной карты и 1,005 для пластиковой.
- Для бензина множитель равен 1,01, независимо от типа карты.
- Для ПЕРФЕКТ и АЛЬФА-ЗАПАД: цена дизеля = база / литры × 0,99; оплата = база × 1,02.
- Расчёт использует Decimal; округление выполняется только для результата, HALF_UP.
- Все коэффициенты и список исключений допускают явную настройку.
- Несколько проверенных договоров одной фирмы объединяются по неокруглённым
  исходным суммам. Цена пересчитывается из общего литража и «Стоимость ТО»;
  среднее из готовых цен не используется. Для исключений наценка клиента
  применяется один раз к сумме базы. Исполнитель проверяет одинаковый ID клиента
  и разные ID договоров. При проверке названий сохраняется организационная форма:
  ООО «ТЕСТ» и АО «ТЕСТ» не объединяются.

## Когда требуется проверка

Расчёт останавливается при неизвестной услуге, отсутствии обязательных колонок,
неясной фирме, несовпадении периода, смешении карт и ненулевой сумме при нулевом
литраже. Для исключительных фирм бензин требует отдельного правила. Скидка в
рублях не считается процентной. Неизвестную скидку не заменяет молчаливое
предположение о типе карты.

Пустой отчёт возвращает `status: no_data`, а полностью возвращённые операции —
`status: fully_reversed`. Эти состояния не означают выполненную активацию.

## Проверки

Автоматические тесты используют синтетические XLSX и проверяют различие колонок,
возвраты, объединение дизеля, исключения, перестановку заголовков, пропуск итогов,
повторяющиеся операции, пустые данные, итоговый нулевой литраж, неизвестные
услуги, идентичность клиента, период и русский формат чисел.

Первый живой экспорт `report_pg_clients_total_detail_discount_for_manager_2026_09_19.xlsx`
содержит всех клиентов, подытоги и скидку в рублях. У него фактические размеры
544 × 16, но объявленная область листа — A1. Поэтому чтение в обычном режиме
предотвращает потерю строк. Этот тип выгрузки отклоняется: он не содержит
колонку «Скидка, %».

Второй экспорт `report_pg_transactions_detail_2026_09_19.xlsx` не содержит
«Стоимость ТО» и «Скидка, %» и также отклоняется.

## Проверка правильного живого экспорта

19.09.2026 через личный кабинет получен «Транзакционный отчёт со скидкой» для
ООО «УНИСТРОЙ», период 15–17.09.2026. Оригинал находится локально в
`data/live-samples/ООО "УНИСТРОЙ".xlsx`; этот каталог содержит рабочие данные.
Фактический лист `transactions` имеет 38 строк и 20 колонок. Заголовок во второй
строке подтверждает J/M/P/S, а операции находятся в строках 6, 7, 13, 14.

Расчёт на настоящем XLSX прошёл без изменения правил:

| Показатель | Результат |
|---|---:|
| Объединённый дизель | 265,450 л |
| Стоимость ТО | 21 080,00 руб |
| Оплата клиента | 21 290,91 руб |
| Цена поставщика | 78,62 руб/л |
| Тип карты по процентной скидке | виртуальная |

Подытоги по картам и общая итоговая таблица исключены из расчёта. Это подтверждает
совместимость парсера с выбранным живым типом выгрузки. Данная проверка сама по
себе не подтверждает полный запуск расписания или выгрузку всех фирм.

Итоговый прогон тестов после объединения калькулятора, исполнителя, API и
коннектора: `109 passed, 3 subtests passed`.

Живой вход и полный список из 32 фирм подтверждены отдельным запуском
`check_connection`: проверены пагинация и совпадение всех ID с карточками.
Импорт правильного XLSX УНИСТРОЙ также прошёл через HTTP API приложения:
получены расчёт, сводный Excel и ZIP; скачанный ZIP проверен на целостность.

Полный автоматический проход всех фирм и новый правильный экспорт СПАЙКА-СЕВЕР
пока не подтверждены. Запуски останавливались при открытии кабинета; 19.09.2026
обновление страницы в обычном пользовательском Chrome также показало
`ERR_TIMED_OUT`. Наличие локальных тестов, списка фирм и одного проверенного
XLSX не заменяет полного прогона. Последний такой запуск:
`b51f4349e4984dfc844b6e6efa980b25`, статус `failed`, исходники не получены.

Расписание на Mac включено по запросу пользователя: вторник/пятница 08:45 МСК,
ближайший запуск 22.09.2026 за 18–21.09.2026. Доступность GloPro и завершение к
09:00 не гарантируются. Неполный комплект не публикуется как готовый.
