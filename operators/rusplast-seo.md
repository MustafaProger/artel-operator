# Новая полезная статья для покупателей гофротрубы каждые четыре дня

Источник фактов — актуальный ассортимент и контекст сайта rusplast-zavod.ru.
При каждом запуске выбрать новый вопрос покупателя с учётом всех опубликованных
статей и истории выпусков. Фиксированного банка готовых статей нет.

Использовать принципы навыка seo-content: ясный вопрос и самостоятельный ответ,
проверяемые источники, редакционная подпись, естественные ключевые слова, полезные
таблицы и списки, уместные внутренние ссылки. Не писать ради объёма или повторения
ключей, не обещать позиции и трафик. Изображения только из approvedImages сайта.
Никаких ИИ-иллюстраций трубы, неподтверждённых цветов и выдуманного опыта.

Писать только подтверждённые факты об ассортименте и советы по закупке. Не
создавать инструкции электромонтажа, не обещать огнестойкость, безопасность,
соответствие ГОСТ/ПУЭ, сертификаты, результаты испытаний, УФ-защиту, срок службы
или допустимость конкретного способа монтажа без первичного подтверждения.
Наличие внешней ссылки само по себе не подтверждает утверждение.

Каждый текст отдельно проверяет редакторская сессия Codex. Автоматические проверки:
структура, даты, подпись, SEO-метаданные, существующие ссылки/изображения,
точные выдержки источников, повтор slug/заголовка/запроса и пересечение интента.
Ошибка останавливает публикацию и отображается в истории оператора.

Публикация выполняется scripts/publish-article.py сайта: проверка, сборка,
пререндер, резервная копия, развёртывание и HTTP-проверка. Результат дополнительно
проверяет оператор. Повтор одного четырёхдневного выпуска использует тот же JSON,
новый дубликат не создаётся. После сна обрабатывается только актуальный выпуск.

Генератор — уже авторизованный локальный Codex CLI с подпиской ChatGPT.
Отдельный API-ключ не требуется. Для запуска Mac должен быть включён, приложение
Артель Оператор запущено, вход ChatGPT и SSH-доступ к сайту действительны.
Ключи и пароли не хранятся в этой инструкции. При истечении входа/лимите Codex
запуск завершается ошибкой, старые статьи и процессы GloPro/Яндекса сохраняются.
