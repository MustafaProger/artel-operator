# Недельные отчёты Яндекс Заправок

Только во вторник за предыдущие вторник–понедельник, полные сутки по Москве.
Например, запуск 22.09.2026 обрабатывает 15–21.09.2026. В пятницу не запускать.

В кабинете ООО НК АРТЭЛЬ получить ВСЕ заказы недели без фильтра сотрудников.
Пройти все страницы до подтверждённого окончания выдачи; ошибка, повтор ID,
неизвестная пагинация или изменение выборки при повторной проверке блокируют итог.
Сотрудников определять по user_id из самих заказов, включая переименованных,
отключённых и отсутствующих в текущем справочнике. Новые участники попадают
автоматически. employee_aliases задаёт только согласованные подписи.
Джибраил в кабинете — Джибриль в подписи. Одноимённые записи не объединять.
До создания файла проверить наличие заказов. Пустые отчёты не создавать и не скачивать.
Для непустой выборки создать новый отчёт; старые файлы из списка не подставлять.
Проверить организацию, неделю, UTC+3, имя и телефон сотрудника, ID заказов,
сумму строк, общий итог и соответствие таблице в кабинете. При расхождениях
требуется проверка, итоговые суммы не публиковать.

Литры брать из «Залито», а не «Запрос». Закупку брать из «Стоимость».
Коэффициенты GloPro не применять. Возвраты и неизвестные статусы требуют проверки.
Для каждого заправлявшегося создавать новый Excel по его user_id.
Сохранять как «Яндекс. <имя>.xlsx»; при совпадении имён добавлять полный ID.
В подписи остальные имена брать из заказов; имя на последнем заказе недели
задаёт отображение, а исторические имена проверяются построчно.
В сводке и архиве соблюдать алфавитный порядок.

Подпись:
```text
15.09 - 21.09
Яндекс заправки
на склад (Джибриль) 1 898,04 л на сумму закупки 179 872,01 рублей
```

Числа в образце не использовать в расчётах: всегда пересчитывать исходные строки.
Результат: текст, Markdown, сводный Excel, исходные файлы и архив с проверкой.
Импорт отдельных файлов допускается и не подтверждает полноту всей недели.
Стандартный XLSX не содержит внутренний user_id: при импорте личность определяется
по полному хешу телефона, для известных подписей — по проверенной привязке.
Неоднозначные привязки не объединять. В автоматическом режиме каждый ID заказа
сопоставляется с user_id кабинета. Разделы Obsidian обновлять по идентификатору;
другие разделы сохранять, повторные заголовки не добавлять. Telegram не используется.

Для автоматической выгрузки нужен однократный вход через «Подключения → Яндекс».
Сессия хранится локально с правами 0600; пароль приложение не запрашивает.
После истечения входа подключение нужно подтвердить заново. Mac должен быть
включён, приложение запущено. Автозапуск включается после проверки подключения.
