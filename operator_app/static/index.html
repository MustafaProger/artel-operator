Как это устроено

Параметры в заголовке YAML задают расписание и правила расчёта. enabled: false выключает автозапуск; ручной запуск остаётся доступен.

Текст ниже заголовка

Markdown хранит описание процесса и прикладывается к запуску. Произвольный текст сам по себе не создаёт новую автоматизацию.

Изменения сохраняются для следующих запусков

ИСТОЧНИКИ ДАННЫХ

Подключения

Подключения к кабинетам поставщиков и получение отчётов.

GloProНе проверено

Данные доступа хранятся локально в файле с ограниченным доступом, без шифрования. Пароль не возвращается в интерфейс и не добавляется в инструкции.

Автозапуск на Mac: оператор включён, приложение работает, Mac не спит.

Один раз подключить

Проверка подтверждает вход в кабинет. Автозапуск включается отдельно в инструкции оператора.

Если кабинет недоступен

Загрузите выгрузки Excel вручную. Они пройдут через тот же расчёт и останутся в истории запусков.

Работа по расписанию

Приложение должно работать, а Mac — быть включённым и не находиться в режиме сна. Оператор должен быть включён; время указывается по Москве.

Яндекс Заправки

Не подключён

Недельные отчёты по всем сотрудникам с заправками: каждый вторник в 07:00 МСК за предыдущие вторник–понедельник. Новые сотрудники добавляются автоматически.

Один раз войдите в ООО «НК АРТЭЛЬ» в отдельном окне «Google Chrome для тестирования». После входа окно закроется, а приложение сохранит сессию для следующих выгрузок. Пароль в приложение вводить не нужно.

По вашему шаблону

Отдельный файл «Яндекс. Имя.xlsx» для каждого сотрудника с заправками. При совпадении имён в название добавляется ID. В тексте — период, литры и сумма закупки на склад.

Проверяются все страницы заказов недели, ID сотрудников и каждая строка Excel. Подтверждённые пустые выборки пропускаются; ошибка загрузки останавливает расчёт.

Если Яндекс попросит повторный вход, нажмите «Подключить Яндекс». До восстановления доступа можно импортировать готовые выгрузки. Импорт проверяет переданные файлы; полноту недели подтверждает автоматический запуск.
